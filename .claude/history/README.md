# History

Chronological log of work sessions on this project. Each entry captures the
goal, the changes, the decisions made, and the resulting state — so future
sessions can pick up without reading old chat transcripts.

## Conventions

- One file per session: `NNN-slug.md`, numbered from 001.
- Always include the date in ISO format (YYYY-MM-DD).
- Capture decisions and rationale, not just file paths. The "why" is what
  survives best across time.
- Note known gotchas explicitly so the next session does not rediscover them.
- Do not edit past entries except to correct factual mistakes (add a note
  inside the file when you do).
